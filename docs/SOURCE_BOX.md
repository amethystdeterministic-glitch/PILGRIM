# Source Box — Canon Definition

A Source Box is the atomic unit of creation in Amethyst.

One Source Box contains:
- A public Source (what people see)
- All pages belonging to that Source
- The full version history of that Source
- Its own Builder context

A Source Box is:
- Self-contained
- Deterministic
- Never overwritten

## Core Rules

1. A Source Box always exists once created.
2. Publishing creates a frozen GREEN state.
3. Editing never mutates GREEN.
4. All edits produce a new version inside the same box.
5. The visible Source always belongs to exactly one box.

## Tiers

- Free tier:
  - One Source Box
  - Full functionality
  - No feature restrictions

- Pro tier (future):
  - Multiple Source Boxes
  - Same rules, same power

Source Boxes scale by quantity, not capability.

This is not a one-page builder.
This is a system for growing complete sites over time.
